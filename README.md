## Project Overview

This project develops an end-to-end MLOps pipeline to predict the daily tea leaf plucking output (kg per worker) using machine learning.

The pipeline includes:

- Data versioning using DVC
- Data quality investigation and preprocessing
- Experiment tracking and model registry using MLflow
- Prediction service using FastAPI
- Containerization using Docker
- Automated testing using GitHub Actions
- Deployment configuration using Kubernetes
- Data drift monitoring and model retraining
- Final predictions on unseen holdout data
